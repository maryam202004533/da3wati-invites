# Davaty: Elegant Wedding Invites

إنشاء موقع إلكتروني احترافي باسم دعوتي



أنشئ موقعًا إلكترونيًا احترافيًا باللغة العربية فقط (RTL) باسم “دعوتي”.



فكرة الموقع



موقع متخصص في تصميم دعوات الزواجات الإلكترونية الفاخرة.



لا يوجد تسجيل دخول أو إنشاء حساب للعملاء.



أي شخص يدخل الموقع يستطيع تعبئة بيانات المناسبة، ثم إرسالها مباشرة عبر واتساب.



⸻



الهوية البصرية



اجعل تصميم الموقع فاخرًا جدًا ويعطي إحساسًا بالرقي والفخامة.



الألوان

	•	الذهبي (#C9A227)

	•	الشامبين (#F5E7C4)

	•	البيج (#F8F3EA)

	•	الأبيض (#FFFFFF)

	•	الرمادي الداكن للنصوص (#3A3A3A)



استخدم تأثيرات زجاجية (Glassmorphism)، وظلال ناعمة، وحركات انتقال سلسة (Fade In - Slide Up - Hover Animation).



⸻



الخطوط



استخدم خطوط عربية جميلة مثل:

	•	IBM Plex Sans Arabic

	•	Noto Kufi Arabic

	•	Cairo



⸻



الصورة الرئيسية (Hero)



لا تستخدم أي صور لأشخاص أو عرسان.



بدلاً من ذلك اجعل الصورة الرئيسية عبارة عن فن عربي تجريدي من الحروف العربية المتداخلة.



المطلوب:

	•	حروف عربية متشابكة بشكل فني.

	•	ليست كلمات مفهومة، وإنما زخارف من الحروف العربية.

	•	مستوحاة من الخط الديواني أو الثلث.

	•	تفاصيل ذهبية فوق خلفية بيج فاتحة.

	•	زخارف عربية وإسلامية بسيطة.

	•	تأثير إضاءة ناعم.

	•	حركة Floating خفيفة عند فتح الصفحة.

	•	التصميم يعطي إحساسًا بالفخامة الخاصة بدعوات الزفاف.



⸻



الشعار



أنشئ شعارًا باسم:



دعوتي



ويكون بجانبه أيقونة عبارة عن حرف د مرسوم بخط عربي فاخر داخل إطار دائري ذهبي.



⸻

القسم الرئيسي



العنوان:



صمم دعوتك الإلكترونية بكل سهولة



وصف قصير يوضح الخدمة.

	•	تسجيل بيانات مناسبتك

	•	الباقات

	•	التواصل عبر واتساب

⸻



صفحة تسجيل بيانات المناسبة



عند الضغط على:



تسجيل بيانات مناسبتك



افتح صفحة تحتوي على نموذج كبير يشمل:

	•	اسم العريس

	•	اسم العروس

	•	تاريخ المناسبة

	•	وقت المناسبة

	•	اسم القاعة

	•	رابط موقع القاعة (Google Maps)

	•	عدد المدعوين

	•	إضافة أسماء المدعوين مع إمكانية إضافة عدد غير محدود

	•	اختيار تصميم الدعوة

	•	اختيار لون الدعوة

	•	كتابة نص الدعوة

	•	رفع صورة للدعوة (اختياري)

	•	رفع موسيقى (اختياري)

0506157964

تم الدخول
